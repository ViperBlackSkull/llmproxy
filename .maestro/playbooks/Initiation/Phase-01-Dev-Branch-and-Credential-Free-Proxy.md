# Phase 01: Dev Branch + Credential-Free Proxy Prototype

This phase establishes the `dev` branch and delivers the core new capability end-to-end: a standalone proxy at `http://localhost:8765` that any agent can point at with **no real credentials** — the daemon loads real keys from `.env`, injects them upstream, and remaps Claude model names to the z.ai GLM models. By the end of this phase a plain `curl` with zero auth headers gets a real completion back through the proxy. This is the foundation everything else (live dashboard, four-agent testing) builds on.

**Context you need:** this is a two-component Go project — `llmproxy` (bash wrapper, tracked in git) and `llmproxyd` (Go daemon, `main.go`, built via `make build`). The working tree currently has a problem: the tracked `llmproxy` bash script has been accidentally overwritten by a 13MB compiled binary (a build artifact). The real script is safe in git HEAD. There is also coherent, finished security work uncommitted in `main.go` + `README.md` (inspect-token auth, secret redaction, file perms, loopback binding). Before writing anything new, search `main.go` for existing helpers (`resolveTarget`, `injectAPIKey`, `isSelfReference`, `detectAPIType`, `getEnv`) — extend them rather than reinventing.
